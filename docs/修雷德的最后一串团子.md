# 修雷德的最后一串团子 · 七合交锋

一支垂直吸盘，十二张纸卡，约 **3 分 40 秒**。水芸请呆猫把三颗兔团子送过画框。黑龙把脖子伸进来，猫数错一次；再数错一次，它就会输。棋盘上沿两列红块分别属于猫和龙，**一块一血，空槽就是零血**。

## 分场演出本

左右方向以观众俯视画面为准。血量按 **呆猫 : 黑龙** 记。时间来自这一版 Python 排练，实机等待到位后才执行下一步。

| 排练时间 | 台上动作与对白 | 回合结束血量 |
|---|---|---|
| 0:00–0:10　送团子 | 水芸在纸上画了三颗兔团子：“送到画框左边，别偷吃。”呆猫屈指去数：“一、二、三……四？”第四颗眨了眨。是黑龙的眼睛。 | **2 : 3** |
| 0:10–0:34　第一合：问路 | 猫上探，龙也抬头；猫向下，龙头就沿对岸原样跟下来。两边同时停住，猫偷看串签，龙先破了规矩，抢进中线。 | **2 : 3** |
| 0:34–0:50　第二合：错身 | 黑龙收翅，贴地冲向串签。猫只让半步，等龙角过去，才从侧面绕到翅根，拿大脑袋一顶。咚。龙晃了晃，猫悄悄摸了摸自己的额头。吸走一块龙血。 | **2 : 2** |
| 0:50–1:18　第三合：回马尾 | 黑龙兜半圈，头朝左，尾巴从下方扫来。猫跳过第一扫，伸出一根爪头：“一！”尾尖忽然弹回，扫到还没收起的小短腿。猫被拨到左上方。吸走一块猫血。猫伸出第二根爪头，这次数对了。 | **1 : 2** |
| 1:18–1:45　第四合：数到三 | 尾尖再来。猫把刚才挨过的两下数给观众听，每次数完都让尾尖打在它上一拍站过的位置。第三根爪头举了半天，龙没招了。 | **1 : 2** |
| 1:45–2:23　第五合：火里护食 | 一把扇形火从龙齿间铺开。呆猫先赶到串签下，把团子直推到左边，再贴着火扇下沿往龙嘴跑。火回库，普通猫换成举刀替身。趁龙合嘴，猫用刀背向上一挑；龙刚闭上的嘴又被磕开。扣掉一块龙血。呆猫回头瞄一眼：团子还在。 | **1 : 1** |
| 2:23–2:58　第六合：剪口 | 吐息与甩尾残影同时留场，上下夹住刀尖。猫虚递一刀，抽身向左；尾影扑进空格时，猫从火扇下方绕到龙腹一侧。两张特效依次撤回，留出决胜的中线。 | **1 : 1** |
| 2:58–3:25　第七合：假退真咬 | 黑龙先缩颈，再沿斜线咬来。猫提前挪开脚，飞翔踢踏向龙颔，升至画面顶端。停一拍。“气刃兜割。”猫已落地，刀光迟半拍才亮。龙退到城垛边；机械臂把它最后一块红片送进弃血区。空槽亮给观众看，黑龙从此停住。 | **1 : 0** |
| 3:25–3:40　交差 | 刀光熄灭，举刀替身退场，普通猫回到串签旁：“一、二、三。给水芸的，一颗都在。”水芸：“那你的报酬呢？”呆猫：“米饭。”想了想，又补了一句：“大碗。” | **1 : 0** |

## 摆台与复位

棋盘 **380 × 296 mm**，格距 **20 mm**，原点在左下角。上沿从左到右排呆猫血槽、黑龙血槽、弃血区。中央演戏，下沿从左到右排吐息库、换偶台、刀光库、甩尾库。所有正面朝上，纸卡方向与印品一致。下表的 XY 都是吸取点，单位为毫米。

| 纸卡（定位 ID） | 印刷尺寸 | 开场 XY |
|---|---:|---|
| 艾露猫（1）、黑龙（2） | 44×44、76×64 | (76,109)、(315,185) |
| 兔团子（3） | 40×32 | (145,154)，推耳在右侧 |
| 扇形吐息（4） | 82×48 | (46,31)，尖端朝右 |
| 举刀猫（5）、兜割刀光（6） | 58×48、54×50 | (128,31)、(242,31) |
| 甩尾残影（7） | 78×48 | (329,31) |
| 两块猫血（8、9） | 各 32×32 | (24,273)、(59,273) |
| 三块龙血（10、11、12） | 各 32×32 | (108,273)、(143,273)、(178,273) |

每次确认命中后，用吸盘搬走一张血块。下表即本场的扣血顺序；所有弃置位的 Y 都是 273 mm，每块单独落位，下一块不会盖住上一块的标记。弃血区内的红块不计入任何一方血量。

| 命中 | 吸走的红块 | 弃置位 X | 落下后 |
|---|---|---:|---|
| 猫以头撞翅根 | 龙血三 · ID 12 | 220 | 2 : 2 |
| 黑龙回扫 | 猫血二 · ID 9 | 254 | 1 : 2 |
| 猫在龙颔下拔刀上挑 | 龙血二 · ID 11 | 288 | 1 : 1 |
| 气刃兜割 | 龙血一 · ID 10 | 322 | 1 : 0 |

终场猫血一留在原槽。再次排练前，将弃置区的四块放回印在棋盘上的对应 ID，并把猫、龙、团子放回开场坐标。四张特效和替身卡由剧本送回各自候场位。

## 打印、定位与演出

- [A3 横向印品，3 页](../examples/print/theater-A3.pdf)：两页拼棋盘，一页剪卡。[A4 横向印品，6 页](../examples/print/theater-A4.pdf)：四页拼棋盘，两页剪卡。用 100% 比例打印并检查页脚的 50 mm 校尺。正式表演前确认舞台各角、候场区和整个血条行都在机械臂可达范围和相机视野内。
- 可在编辑器的血条设置里改所属角色、槽区和格数，或绑定已有道具。把某个血块从本方槽区移入弃血区，预演就会少一格。区内剩余块数由绑定纸卡吸点的实际 XY 算出；演出中的动作顺序和命中时机由剧本规定。
- 检查实场照片时，可用 `.venv/bin/python -m armischestra score --project examples/schrade.armischestra.json --calibration hardware.local.json --image stage.jpg`。让相机同时看见两个血槽和弃血区。有血块标记被遮住时，程序提示未确认；它不会把遮挡误报为零血。
- 只有推团子使用一次低位侧推，示例接触距离 `push_back_mm=22`。实测推耳、吸盘及接触高度后再启用 `arm.contact_push_enabled`；也可把这一步改成吸移，终点仍是 (78,154)。其余动作均可吸起、移动、放下。固定观察位只用于必要的退让，正常演出没有逐步回原点。
- 翔起和落刀用棋盘上的弧线、停顿和替身表现，竖直吸盘只需两档高度。实机仍需在实际纸片、气管和光照条件下试走全程。
