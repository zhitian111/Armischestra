# 两张主角卡的出处

**呆猫用水芸画的那只。** 这只艾露猫是《怪物猎人：崛起》中炎火村集会所接待员水芸（ミノト / Minoto）为《狩猎指南书》设计的角色。卡普空简中正文直接称它为“猫”，随从外观叫“猫系列”，英文名 **Kit T.**，繁中名“小苗”，日文名“ネコ”。它在五个兄弟姐妹中排行最小，最爱吃米饭。剧中“呆猫”是观众的昵称，提到饭时那张小圆脸终于有了明确的行动理由。[Capcom 简中「猫系列」角色介绍](https://store.steampowered.com/app/2167453/?l=schinese) · [英文 Kit T.](https://store.steampowered.com/app/2167453/?l=english) · [繁中「小苗」](https://store.steampowered.com/app/2167453/?l=tchinese) · [日文「ネコ」](https://store.steampowered.com/app/2167453/?l=japanese) · [水芸的简中角色条目](https://store.steampowered.com/app/1798002/?l=schinese)

官方外观截图里的猫有蓝紫色尖耳兜帽，帽口露出米黄色圆脸、两只圆眼和一张小巧的 W 形嘴；身体与手脚短小，背后垂着一截深色围巾。贴图把脸进一步缩小，让五官挤在正中央。举拇指那张可以清楚看见这个比例。另一张同时画了两只随从，画面右上角长脸、额上白叉的是犬，右下方小圆脸才是猫。若要重绘彩印图，先保住这张小圆脸，定位标记尽量留在空白处。用呆猫面无表情地等半拍作笑点，比给它画一张凶脸更贴合这套图。[官方游戏截图](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/2167453/ss_073cc62744a34bc81a5fe2b33768ab8134a5b0c3.600x338.jpg) · [官方贴图近景](https://stickershop.line-scdn.net/stickershop/v1/sticker/648271808/android/sticker.png) · [官方犬猫同框图](https://stickershop.line-scdn.net/stickershop/v1/sticker/648271809/android/sticker.png)

**黑龙用《世界：冰原》的 Fatalis。** 这头传说中的黑龙在《冰原》第五次大型免费更新登场，决战地点为修雷德城（Castle Schrade）。一夜毁国在作品中以传说的口吻讲述。官方截图可作为纸偶剪影依据，长颈让头部清楚地伸到双翼前方，长尾把轮廓拖向后方。舞台上的火焰可以画成一端窄、一端宽的扇片，窄端对准龙嘴，让观众看懂呆猫必须逃到火线侧面。[Capcom 开发者日志与预告](https://news.capcomusa.com/lets/browse/monster-hunter-world-iceborne-developer-diary-the-final-stand-introduces-the-legendary-black-dragon-fatalis-and-much-more) · [PlayStation 的黑龙、修雷德城及烈火截图](https://blog.ja.playstation.com/2020/10/01/20201001-mhw/)

**登龙按《崛起》的太刀节奏表演。** 先借翔虫使出飞翔踢，踢中后起跳，然后在下落时衔接气刃兜割（Spirit Helm Breaker）。桌面镜头里可以把踢跃画成斜向上场的路径，在顶点停一个短拍，再让另一张多道斩痕的纸片出现。这样观众看得到“先蓄势、后落刀”的次序，猫与刀可以预先印成一张剪影。[《Monster Hunter Rise》太刀官方演示](https://www.youtube.com/watch?v=0Re7R7k554U) · [任天堂香港官方频道简中动作指南](https://www.youtube.com/watch?v=MXp4bOcgsME)

本剧让水芸画里的猫借用猎人的太刀招式，在修雷德的纸上舞台迎战《冰原》的黑龙。跨作品相遇、台词和战果属于本次剧场的原创编排。
